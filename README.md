# OpenFootLab Testnet

A client-friendly prototype for OpenFootLab with responsive navigation, client and clinician pathways, and a three-step intake demo.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL shown by Vite. Build production files with `npm run build`.

## Testnet privacy

The intake demo does not transmit or persist information. It must be connected to an approved secure backend before accepting real client or patient data.
